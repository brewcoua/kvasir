# kvasir-types

Types and small pure functions shared by every kvasir crate.

## Modules

Under `src/`.

| Module | Holds |
| --- | --- |
| `requests.rs` | What the routes take, method options included. |
| `results.rs` | What a run produces. |
| `runs.rs` | A run as the registry serves it: state, progress, calls, searches and usage. |
| `pages.rs` | The page cache as the knowledge page shows it. |
| `sites.rs` | Host keys, and the kinds and tags a source can carry. |
